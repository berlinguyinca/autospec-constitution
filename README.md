# autospec-constitution

Public constitution, governance rules, and operating principles for the autospec ecosystem.

This repository works with `berlinguyinca/autospec` by keeping durable policy and decision records separate from the implementation repository. Autospec agents and maintainers can use it as the source of truth for cross-repository expectations, review standards, autonomy boundaries, and quality bars.

## Relationship to autospec

- `autospec` implements the workflows, scripts, skills, and automation.
- `autospec-constitution` records the durable rules those workflows should obey.
- Changes here should be treated as governance inputs for future autospec specs, issues, and implementation work.
